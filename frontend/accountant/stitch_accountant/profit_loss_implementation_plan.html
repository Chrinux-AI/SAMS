Helper Calculation Map To support this page, the following backend aggregations are required: - `get_revenue_by_period($tenant_id, $start, $end)`: Sum of all revenue-type ledger entries. - `get_expenses_by_period($tenant_id, $start, $end)`: Sum of all expense-type ledger entries. - `calculate_net_income($revenue, $expenses)`: Simple subtraction for the bottom line. - `calculate_operating_margin($net_income, $revenue)`: (Net Income / Total Revenue) * 100. - `get_prior_period_comparison($tenant_id, $current_start, $current_end)`: Fetches data for the immediately preceding equivalent period. ### 💾 3. SQL Logic (Conceptual) ```sql -- Aggregating totals for the P&L table SELECT coa.account_name, coa.account_type, SUM(le.credit - le.debit) as balance FROM ledger_entries le JOIN chart_of_accounts coa ON le.account_id = coa.id WHERE le.tenant_id = ? AND le.entry_date BETWEEN ? AND ? AND coa.account_type IN ('revenue', 'expense') GROUP BY coa.id; ``` ### ✅ 4.
